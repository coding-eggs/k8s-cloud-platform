# 镜像仓库 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让平台里填镜像不再靠背 —— 两处镜像输入框有 repository / tag 补全，另有一个只读浏览页能沿层级往下钻并复制完整镜像地址。

**Architecture:** 把「镜像仓库的方言」抽成 `RegistryDialect` 接口 + 按 `platform_credential.type` 查表分派，本批只实现 `HarborDialect`。候选与浏览都走**路径驱动**：后端解析用户输入的整串、后端给面包屑、候选直接返回**要填进输入框的完整字符串** —— 于是前端完全不认方言，将来加一档不动前端。

**Tech Stack:** Spring Boot 4.1 / Java 21 / MyBatis / MySQL / Vue 3 + Element Plus + TypeScript

**Spec:** `docs/superpowers/specs/2026-10-14-registry-design.md`

## Global Constraints

- **本批只实现 Harbor 一档**。`type` 枚举本批只到 `GIT | HARBOR`，**不预放空值**；扩展位由接口 + 分派表 + 护栏测试提供。
- **必须是 `tenant:` 前缀的权限码**：`RoleService.assertScopeMatches`（`platform-api/.../services/RoleService.java:149`）规定 TENANT 角色只能持 `tenant:` 码，而补全与浏览页的使用者是租户。
- **本仓没有 Flyway**：`db/migration/*.sql` 是**手工重放**的。
- **MySQL 注释 `--` 后面必须跟空白字符**，否则整个文件重放失败。
- **迁移可重放**：显式 id + `ON DUPLICATE KEY UPDATE`；角色关联按**显式 id 列表，绝不用 LIKE**。
- ⚠️ **角色关联的 `permission_id` 必须与权限行的 `id` 逐字一致**。本仓**不加外键**，写错了不报任何错，只留一条**悬空关联**（症状：码在库里、角色却没有它，菜单不显示且日志安静）。S0.2 交付当天就踩过（`perm_credential_page` vs `perm_page_credential`）。**验收必须做 join 对账，不能只数行数。**
- ⚠️ **出站客户端必须真正关掉重定向**：`SimpleClientHttpRequestFactory` 基于 `HttpURLConnection`，**没有**关重定向的 API 且默认跟随。必须用 `JdkClientHttpRequestFactory` + 显式 `HttpClient.Redirect.NEVER`（S0.2 终审抓到过一个 Critical 就是「文档写 NEVER、代码在跟随」）。
- **错误码**：`EnumResponseType` 当前最大是 `10036`，新码从 **10037** 起。
- **测试命令必须带 `-Dsurefire.failIfNoSpecifiedTests=false`**。
- **既有失败勿当本批引入**：`k8s-core` 的 `WorkloadConverterStaticIpTest` 在 @HEAD 即 NPE（工作区里它的文件是被有意删掉的，所以不会跑）。
- **不提交**工作区里预存的两处用户改动：`platform-api/src/main/resources/application.yaml`（aes-key 默认值）、`platform-common/.../AESUtils.java`（main 方法）、以及 `k8s-core` 那个测试文件的删除。

## Review Focus

以下五类是本模块最容易被真实输入打穿、而任何单测都不会替你想到的地方。**每条都在它所属的任务里有一条测试钉住**：

1. **用户输入的 host 被拿去构造出站地址** —— 那等于给了调用方一个「让服务器去打任意地址」的口子。合理预期：出站 URL **只由凭据的 `endpoint` 拼**，用户输入只用于匹配连接。→ Task 4 + Task 8。
2. **`harbor.example.com.evil.com` 匹配上了 `harbor.example.com` 这条连接** —— 朴素的 `startsWith` 就会中。合理预期：host 边界必须在 `/`、`:` 或串尾。→ Task 4。
3. **匹配不到任何连接时仍然发了请求** —— 白等一次超时，还可能把内网探测结果暴露成延迟差。合理预期：零请求。→ Task 4 + Task 8。
4. **补全失败弹错误条** —— 它是每按键一次的高频动作，弹错会掩盖真正的问题，也会让用户以为「填不了镜像」。合理预期：静默空候选，输入框仍能自由输入。→ Task 6。
5. **加了一档方言、忘了写实现** —— 枚举里有值、分派表里没有，运行时才炸。合理预期：构建期就红。→ Task 3 的护栏测试。

```java
package com.coding.platformapi.registry;

import java.util.Comparator;
import java.util.List;

/**
 * 把用户在输入框里打的整串，归到某一条已配的连接上。**纯函数、无 IO。**
 *
 * <p>设计见 docs/superpowers/specs/2026-10-14-registry-design.md §4.1。三条硬边界都在这里：
 * <ol>
 *   <li><b>host 边界必须在 {@code /}、{@code :} 或串尾</b> —— 否则
 *       {@code harbor.example.com.evil.com} 会冒充 {@code harbor.example.com}；</li>
 *   <li><b>最长 endpoint 优先</b> —— 同 host 带端口与不带端口同时配上时，取更具体的；</li>
 *   <li><b>匹配不到一律返回 {@code null}</b> —— 调用方据此**不发任何请求**。</li>
 * </ol>
 *
 * <p>⚠️ 本类**只用来挑连接**。出站 URL 一律由被挑中的那条连接的 {@code endpoint} 拼 ——
 * <b>绝不拿用户输入里的 host 去构造目标地址</b>（那等于给调用方一个打任意地址的口子）。
 */
public final class RegistryTargetResolver {

    private RegistryTargetResolver() {
    }

    /** Docker 的保留判定：裸的 `localhost` 也算 registry host（本机 registry 常这么写）。 */
    private static final String LOCALHOST = "localhost";

    /**
     * 取 registry host。**不是每段首段都是 host** —— 镜像引用有两种写法：
     * `harbor.example.com/proj/app`（首段是 host）vs `myteam/app`（首段是 Docker Hub 的命名空间）。
     * 判据用 **Docker 自己的规则**：首段含 `.` 或 `:`，或恰为 `localhost`。
     * 单靠「第一个 `/` 之前」会把 `myteam/app` 判成 host `myteam` —— 那是错的。
     */
    public static String hostOf(String imagePrefix) {
        if (imagePrefix == null) {
            return "";
        }
        String s = imagePrefix.trim();
        int slash = s.indexOf('/');
        String head = slash >= 0 ? s.substring(0, slash) : s;
        // 不带斜杠的整串可能形如 host:1.2 —— 冒号后不是纯数字端口时才当 tag 剥。
        int colon = head.lastIndexOf(':');
        if (colon > 0 && slash < 0 && !isPort(head.substring(colon + 1))) {
            head = head.substring(0, colon);
        }
        return isRegistryHost(head) ? head : "";
    }

    /** Docker 的规则：含 `.` / `:`，或恰为 `localhost`。 */
    private static boolean isRegistryHost(String head) {
        return head.contains(".") || head.contains(":") || LOCALHOST.equals(head);
    }

    /**
     * 挑出该归哪条连接。取 {@code endpoint} 的**最长前缀匹配**；匹配不到返回 {@code null}。
     *
     * @param candidates 已启用、且 type 属于镜像仓库的连接
     */
    public static CredentialRef match(String imagePrefix, List<CredentialRef> candidates) {
        String host = hostOf(imagePrefix);
        if (host.isEmpty() || candidates == null || candidates.isEmpty()) {
            return null;
        }
        String full = imagePrefix.trim();
        return candidates.stream()
                .filter(c -> boundaryMatches(full, c.endpoint()))
                .max(Comparator.comparingInt(c -> c.endpoint().length()))
                .orElse(null);
    }

    /** {@code full} 以 {@code endpoint} 开头，且其后是 {@code /}、{@code :} 或串尾。 */
    private static boolean boundaryMatches(String full, String endpoint) {
        if (endpoint == null || endpoint.isEmpty() || !full.startsWith(endpoint)) {
            return false;
        }
        if (full.length() == endpoint.length()) {
            return true;
        }
        char next = full.charAt(endpoint.length());
        return next == '/' || next == ':';
    }

    private static boolean isPort(String s) {
        if (s.isEmpty()) {
            return false;
        }
        for (int i = 0; i < s.length(); i++) {
            if (!Character.isDigit(s.charAt(i))) {
                return false;
            }
        }
        return true;
    }
}
```

```java
package com.coding.platformapi.registry;

import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;
import org.springframework.web.util.UriUtils;

import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

/**
 * Harbor 方言。设计见 docs/superpowers/specs/2026-10-14-registry-design.md §2.3。
 *
 * <p><b>走 Harbor 自己的 REST API</b>，不走 Docker Registry V2 的 {@code _catalog} ——
 * Harbor 默认关闭 catalog，且它的权限模型在自己的 API 里（分析文档 §7.5）。
 *
 * <p>本类里凡是**不掺 IO** 的部分都是 {@code static} 且可单测（照 {@code CredentialProbe} 的样子）：
 * 输入切分、URL 构造、响应映射、面包屑。发请求那一层在 {@link RegistryHttpClient}。
 */
@Slf4j
@Component
public class HarborDialect implements RegistryDialect {

    static final int PAGE_SIZE = 100;

    @Override
    public String type() {
        return "HARBOR";
    }

    // ==================== 两个动作（Task 7 接上出站后实现） ====================
    // ⚠️ 本任务必须先放上这两个占位方法 —— RegistryDialect 声明了它们，
    //    只有静态纯规则而不实现接口，本类**编译不过**。

    @Override
    public List<String> suggest(CredentialRef cred, String imagePrefix) {
        throw new UnsupportedOperationException("Task 7 接上 RegistryHttpClient 后实现");
    }

    @Override
    public BrowseResult browse(CredentialRef cred, List<String> path) {
        throw new UnsupportedOperationException("Task 7 接上 RegistryHttpClient 后实现");
    }

    // ==================== 输入切分（纯） ====================

    /** 去掉 host 之后按 {@code /} 切的段。{@code harbor.example.com/proj/app} → {@code [proj, app]}。 */
    public static List<String> segmentsOf(String imagePrefix, String endpoint) {
        String s = imagePrefix == null ? "" : imagePrefix.trim();
        if (!s.startsWith(endpoint)) {
            return List.of();
        }
        String rest = s.substring(endpoint.length());
        while (rest.startsWith("/") || rest.startsWith(":")) {
            rest = rest.substring(1);
        }
        if (rest.isEmpty()) {
            return List.of();
        }
        return Arrays.stream(rest.split("/")).filter(x -> !x.isEmpty()).toList();
    }

    /** 有 {@code :} 时返回 tag 前缀，否则 {@code null}。 */
    public static String tagPrefixOf(String imagePrefix) {
        String s = imagePrefix == null ? "" : imagePrefix.trim();
        int slash = s.lastIndexOf('/');
        int colon = s.indexOf(':', slash + 1);
        return colon >= 0 ? s.substring(colon + 1) : null;
    }

    /** 补仓库时的搜索词 = host 之后唯一那一段；打了斜杠（已进仓库）或只打了 host 时为 {@code null}。 */
    public static String searchTermOf(String imagePrefix, String endpoint) {
        List<String> segs = segmentsOf(imagePrefix, endpoint);
        return segs.size() == 1 ? segs.get(0) : null;
    }

    // ==================== URL 构造（纯） ====================

    public static String projectsUrl(CredentialRef c) {
        return base(c) + "/api/v2.0/projects?page_size=" + PAGE_SIZE;
    }

    public static String repositoriesUrl(CredentialRef c, String project) {
        return base(c) + "/api/v2.0/projects/" + enc(project) + "/repositories?page_size=" + PAGE_SIZE;
    }

    public static String searchUrl(CredentialRef c, String keyword) {
        return base(c) + "/api/v2.0/search?q=" + enc(keyword);
    }

    public static String artifactsUrl(CredentialRef c, String project, String repository) {
        return base(c) + "/api/v2.0/projects/" + enc(project)
                + "/repositories/" + enc(repository) + "/artifacts?page_size=" + PAGE_SIZE;
    }

    private static String base(CredentialRef c) {
        String e = c.endpoint().trim();
        while (e.endsWith("/")) {
            e = e.substring(0, e.length() - 1);
        }
        return e.startsWith("http://") || e.startsWith("https://") ? e : "https://" + e;
    }

    private static String enc(String s) {
        return UriUtils.encodePathSegment(s, StandardCharsets.UTF_8);
    }

    // ==================== 候选串：**完整字符串**（纯） ====================

    public static List<String> repositoryCandidates(CredentialRef c, String project, List<String> repos) {
        List<String> out = new ArrayList<>();
        for (String r : repos) {
            String path = r.startsWith(project + "/") ? r.substring(project.length() + 1) : r;
            out.add(host(c) + "/" + project + "/" + path);
        }
        return out;
    }

    public static List<String> tagCandidates(CredentialRef c, String project, String repo, List<String> tags) {
        return tags.stream().map(t -> host(c) + "/" + project + "/" + repo + ":" + t).toList();
    }

    private static String host(CredentialRef c) {
        return c.endpoint().replaceFirst("^https?://", "").replaceAll("/+$", "");
    }

    // ==================== 浏览映射（纯） ====================

    public static BrowseResult mapProjects(CredentialRef c, List<String> names) {
        List<BrowseResult.Node> nodes = names.stream()
                .map(n -> new BrowseResult.Node(n, true, null, List.of()))
                .toList();
        return new BrowseResult(List.of(), nodes);
    }

    public static BrowseResult mapRepositories(CredentialRef c, List<String> path, List<String> repos) {
        String project = path.get(0);
        List<BrowseResult.Node> nodes = repos.stream()
                .map(r -> new BrowseResult.Node(r, true, null, List.of()))
                .toList();
        return new BrowseResult(List.of(new BrowseResult.Crumb(project, List.of(project))), nodes);
    }

    public static BrowseResult mapArtifacts(CredentialRef c, List<String> path, List<TagInfo> tags) {
        String project = path.get(0);
        String repo = path.get(1);
        List<BrowseResult.Node> nodes = tags.stream().map(t -> new BrowseResult.Node(
                t.tag(),
                false,
                host(c) + "/" + project + "/" + repo + ":" + t.tag(),
                List.of(new BrowseResult.Detail("推送时间", t.pushedAt() == null ? "—" : t.pushedAt()),
                        new BrowseResult.Detail("大小", formatSize(t.size()))))).toList();
        return new BrowseResult(List.of(
                new BrowseResult.Crumb(project, List.of(project)),
                new BrowseResult.Crumb(repo, List.of(project, repo))), nodes);
    }

    /** Harbor artifact 的人类可读 tag 在 {@code tags[0].name}；空数组时退回 artifact.name（那是 digest）。 */
    public static String tagNameOf(String[] tags, String fallback) {
        return tags != null && tags.length > 0 ? tags[0] : fallback;
    }

    public static String formatSize(long bytes) {
        if (bytes <= 0) {
            return "—";
        }
        if (bytes < 1024) {
            return bytes + " B";
        }
        double kb = bytes / 1024.0;
        if (kb < 1024) {
            return String.format("%.1f KB", kb);
        }
        return String.format("%.1f MB", kb / 1024.0);
    }

    /** 从 Harbor artifact 里挑出来的一行（响应映射的中间形态，便于单测） */
    public record TagInfo(String tag, String pushedAt, long size) {
    }
}
```

```java
package com.coding.platformapi.registry;

import com.coding.common.exception.CloudPlatformException;
import com.coding.common.exception.EnumResponseType;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.HttpHeaders;
import org.springframework.http.client.JdkClientHttpRequestFactory;
import org.springframework.stereotype.Component;
import org.springframework.web.client.RestClient;

import java.net.URI;
import java.net.http.HttpClient;
import java.nio.charset.StandardCharsets;
import java.time.Duration;
import java.util.Base64;

/**
 * 镜像仓库的只读出站。设计见 spec §2.4。
 *
 * <p>与 S0.2 的 {@code CredentialProbeClient} **同一条路径与同一套规矩**：显式超时、
 * <b>重定向 NEVER</b>、Basic 认证、失败转业务码。
 *
 * <p>⚠️ <b>重定向必须真正关掉</b>：{@code SimpleClientHttpRequestFactory} 基于
 * {@code HttpURLConnection}，**没有**关重定向的 API 且默认跟随 —— S0.2 终审抓到过一个 Critical
 * 就是「javadoc 声称 NEVER、代码却在跟随」。这里直接用 {@link JdkClientHttpRequestFactory} +
 * 显式 {@code HttpClient.Redirect.NEVER}。
 *
 * <p>⚠️ <b>URL 由调用方给，且必须由凭据的 endpoint 拼出来</b> —— 本类不做任何拼接，
 * 也就不可能拿用户输入里的 host 去发请求（spec §4.2 的硬边界 1）。
 */
@Slf4j
@Component
public class RegistryHttpClient {

    private static final int CONNECT_TIMEOUT_MS = 5_000;

    private static final int READ_TIMEOUT_MS = 10_000;

    private final RestClient restClient;

    public RegistryHttpClient() {
        HttpClient http = HttpClient.newBuilder()
                .followRedirects(HttpClient.Redirect.NEVER)
                .connectTimeout(Duration.ofMillis(CONNECT_TIMEOUT_MS))
                .build();
        JdkClientHttpRequestFactory factory = new JdkClientHttpRequestFactory(http);
        factory.setReadTimeout(Duration.ofMillis(READ_TIMEOUT_MS));
        this.restClient = RestClient.builder().requestFactory(factory).build();
    }

    /** 测试用：注入一个绑定了 {@code MockRestServiceServer} 的 RestClient。 */
    RegistryHttpClient(RestClient restClient) {
        this.restClient = restClient;
    }

    /**
     * GET 一个绝对 URL，返回响应体。
     *
     * <p>非 2xx 一律抛 {@link CloudPlatformException}：调用方（suggest / browse）各自决定
     * 是**静默吞掉**（补全）还是**往上抛**（浏览）—— 见 spec §5.3 的姿态差异。
     */
    public String get(CredentialRef cred, String url) {
        try {
            return restClient.get()
                    .uri(URI.create(url))
                    .header(HttpHeaders.AUTHORIZATION, basic(cred))
                    .retrieve()
                    .onStatus(status -> status.value() == 401 || status.value() == 403, (req, res) -> {
                        throw new CloudPlatformException(EnumResponseType.CREDENTIAL_INVALID,
                                "凭据不通过，或该凭据无权访问此仓库");
                    })
                    .onStatus(status -> !status.is2xxSuccessful(), (req, res) -> {
                        throw new CloudPlatformException(EnumResponseType.CREDENTIAL_INVALID,
                                "镜像仓库返回 " + res.getStatusCode().value());
                    })
                    .body(String.class);
        } catch (CloudPlatformException e) {
            throw e;
        } catch (IllegalArgumentException e) {
            // URI.create 对「不是绝对地址 / 含非法字符」抛这个 —— 那是**地址格式**问题，不是网络问题。
            // S0.2 的教训：把它报成「网络不可达」会把管理员引去查平台出站策略。
            log.warn("镜像仓库地址格式非法 url={}", url, e);
            throw new CloudPlatformException(EnumResponseType.CREDENTIAL_INVALID,
                    "镜像仓库地址格式不对：请检查该连接配置的 endpoint");
        } catch (Exception e) {
            log.warn("镜像仓库请求失败 url={}", url, e);
            throw new CloudPlatformException(EnumResponseType.CREDENTIAL_INVALID,
```

```java
    @Override
    public List<String> suggest(CredentialRef cred, String imagePrefix) {
        // 补全**静默降级**：任何失败都退回空候选，绝不弹错、绝不阻塞输入（spec §5.3）
        try {
            String tagPrefix = tagPrefixOf(imagePrefix);
            List<String> segs = segmentsOf(imagePrefix, cred.endpoint());

            if (tagPrefix != null) {
                // 已进入某仓库 → 补 tag。段不足 2（还没写全 project/repo）时给不出候选。
                if (segs.size() < 2) {
                    return List.of();
                }
                String project = segs.get(0);
                String repo = String.join("/", segs.subList(1, segs.size()));
                List<TagInfo> tags = parseArtifacts(http.get(cred, artifactsUrl(cred, project, repo)));
                return tagCandidates(cred, project, repo,
                        tags.stream().map(TagInfo::tag)
                            .filter(t -> t.toLowerCase().startsWith(tagPrefix.toLowerCase())).toList());
            }

            // 还没进仓库 → 补仓库，只认「host 之后正好一段」的形态
            String term = searchTermOf(imagePrefix, cred.endpoint());
            if (term == null || term.isEmpty()) {
                return List.of();
            }
            List<String> hits = parseSearchHits(http.get(cred, searchUrl(cred, term)));
            // Harbor 的命中形如 proj/repo；投影成用户输入框里的完整串时，把 proj 提出来
            return hits.stream()
                    .filter(h -> h.contains("/"))
                    .map(h -> {
                        String project = h.substring(0, h.indexOf('/'));
                        String repo = h.substring(h.indexOf('/') + 1);
                        return host(cred) + "/" + project + "/" + repo;
                    })
                    .toList();
        } catch (Exception e) {
            log.warn("镜像候选查询失败（静默降级为空）prefix={}", imagePrefix, e);
            return List.of();
        }
    }

    @Override
    public BrowseResult browse(CredentialRef cred, List<String> path) {
        // 浏览**不吞错**：用户在页面上主动点了一层，什么都不说等于页面坏了（spec §5.3）
        if (path == null || path.isEmpty()) {
            return mapProjects(cred, parseProjectNames(http.get(cred, projectsUrl(cred))));
        }
        if (path.size() == 1) {
            List<String> repos = parseRepositoryNames(http.get(cred, repositoriesUrl(cred, path.get(0))));
            String project = path.get(0);
            // Harbor 的 repositories[].name 是 "project/repo"，第二层只显示 repo 部分
            List<String> shortNames = repos.stream()
                    .map(r -> r.startsWith(project + "/") ? r.substring(project.length() + 1) : r)
                    .toList();
            return mapRepositories(cred, path, shortNames);
        }
        if (path.size() == 2) {
            return mapArtifacts(cred, path, parseArtifacts(
                    http.get(cred, artifactsUrl(cred, path.get(0), path.get(1)))));
        }
        return new BrowseResult(List.of(), List.of());
    }
```

```java
        return mapper.selectAll().stream()
                .filter(c -> isRegistry(c) && enabled(c))
                .map(c -> new RegistryConnectionView(c.getId(), c.getName(), c.getType(), c.getEndpoint()))
                .toList();
    }

    /** 补全。匹配不到任何连接 → 空列表，**且不发任何请求**。 */
    public RegistrySuggestResponse suggest(String imagePrefix) {
        if (!StringUtils.hasText(imagePrefix)) {
            return new RegistrySuggestResponse(List.of());
        }
        CredentialRef cred = RegistryTargetResolver.match(imagePrefix, enabledRegistryRefs());
        if (cred == null) {
            return new RegistrySuggestResponse(List.of());
        }
        return new RegistrySuggestResponse(dialects.of(cred.type()).suggest(cred, imagePrefix.trim()));
    }

    /** 浏览。**不吞错** —— 用户在页面上主动点了一层，失败要说（spec §5.3）。 */
    public BrowseResult browse(RegistryBrowseRequest req) {
        PlatformCredential row = mapper.selectById(req.getCredentialId());
        if (row == null || !isRegistry(row) || !enabled(row)) {
            throw new CloudPlatformException(EnumResponseType.CREDENTIAL_NOT_EXIST,
                    "镜像仓库连接不存在或已停用");
        }
        CredentialRef cred = toRef(row);
        List<String> path = req.getPath() == null ? List.of() : req.getPath();
        return dialects.of(cred.type()).browse(cred, path);
    }

    /**
     * 可参与匹配的连接。**这里已经把凭据解出来了** —— 返回的 {@link CredentialRef} 含明文，
     * 只在本进程内传给方言，绝不外泄。
     */
    private List<CredentialRef> enabledRegistryRefs() {
        return mapper.selectAll().stream()
                .filter(c -> isRegistry(c) && enabled(c))
                .map(this::toRef)
                .toList();
    }

    private CredentialRef toRef(PlatformCredential c) {
        CredentialSecret s = fromJson(cipher.decrypt(c.getSecretEncrypted()));
        return new CredentialRef(c.getId(), c.getName(), c.getType(), c.getEndpoint(),
                s.getUsername(), s.getSecret());
    }

    private static boolean isRegistry(PlatformCredential c) {
        return REGISTRY_TYPES.contains(c.getType());
    }

    private static boolean enabled(PlatformCredential c) {
        return c.getEnabled() != null && c.getEnabled() == 1;
    }

    private static final JsonMapper JSON = JsonMapper.builder().build();

    private static CredentialSecret fromJson(String json) {
        try {
            return JSON.readValue(json, CredentialSecret.class);
        } catch (Exception e) {
            throw new CloudPlatformException(EnumResponseType.CREDENTIAL_CIPHERTEXT_INVALID,
                    "凭据内容无法解析（密文损坏或主密钥与写入时不一致）");
        }
    }
}
```

```ts
/**
 * 写剪贴板，返回是否成功。
 *
 * <p>两条路都必须有：`navigator.clipboard` 只在**安全上下文**（https 或 localhost）存在 ——
 * 这套平台常部署在 `http://<内网IP>:端口` 上，那里 `navigator.clipboard` 是 undefined
 * （不是"权限被拒"，是压根没有这个 API），只写新 API 的复制按钮在那类环境里会**静默失效**。
 * 故回退到 textarea + `execCommand('copy')`（已废弃但仍是 http 下唯一可用的路径）。
 *
 * <p>本函数原先长在 `YamlBlock.vue` 里；S3.1 的浏览页也要复制，于是抽出来共用 ——
 * 复制两份的话，下一个人修了一处、漏了另一处就会分叉。
 */
export async function writeClipboard(text: string): Promise<boolean> {
  if (navigator.clipboard && window.isSecureContext) {
    try {
      await navigator.clipboard.writeText(text)
      return true
    } catch {
      /* 权限被拒 / 非用户手势 → 走下面的兜底 */
    }
  }
  try {
    const ta = document.createElement('textarea')
    ta.value = text
    ta.setAttribute('readonly', '')
    // 不能 display:none（选不中），故移出视口
    ta.style.cssText = 'position:fixed;top:-1000px;left:-1000px;opacity:0'
    document.body.appendChild(ta)
    ta.select()
    const ok = document.execCommand('copy')
    document.body.removeChild(ta)
    return ok
  } catch {
    return false
  }
}
```

- [ ] **Step 1: 写一个可复用的 fetch 函数（放 WorkloadView，另一处 import）**

在两处都要用，所以放进一个 composable。创建 `platform-web/src/composables/useImageSuggest.ts`：

```ts
import { registryApi } from '@/api'
import { apiCodes } from '@/apiCodes'
import { usePermission } from '@/stores/permission'

/**
 * 镜像输入框的候选补全（S3.1）。
 *
 * <p>三条规矩，缺一不可：
 * <ol>
 *   <li><b>无权限时不发请求</b> —— 与 frontend-permission-conventions §4 的「可选拉取短路」同一条；</li>
 *   <li><b>失败静默</b> —— 返回空候选，不弹错。补全是每按键一次的高频动作，弹错会掩盖真正的问题，
 *       也会让用户以为「填不了镜像」（spec §5.3）；</li>
 *   <li><b>选中即整段替换</b> —— 后端给的候选已经是完整镜像串，前端不做任何拼接。</li>
 * </ol>
 */
export function useImageSuggest() {
  const perm = usePermission()

  function fetchImageSuggestions(
    query: string,
    cb: (items: { value: string }[]) => void,
  ): void {
    const q = (query ?? '').trim()
    if (!q || !perm.has(apiCodes.registryCatalog)) {
      cb([])
      return
    }
    registryApi
      .suggest(q)
      .then((r) => cb((r.items ?? []).map((v) => ({ value: v }))))
      .catch(() => cb([])) // 静默降级：候选为空不是错误态
  }

  return { fetchImageSuggestions }
}
```

```vue
<script setup lang="ts">
import { onMounted, ref } from 'vue'
import { ElMessage } from 'element-plus'
import { registryApi } from '@/api'
import type { RegistryBrowseResult, RegistryConnectionView, RegistryNode } from '@/types'
import { writeClipboard } from '@/utils/clipboard'

const connections = ref<RegistryConnectionView[]>([])
const credentialId = ref('')
const path = ref<string[]>([])
const result = ref<RegistryBrowseResult | null>(null)

const loading = ref(false)
/** 与「这一层是空的」区分开 —— 浏览失败必须让用户看见（spec §5.3） */
const error = ref('')

async function loadConnections(): Promise<void> {
  connections.value = await registryApi.connections()
  if (connections.value.length && !credentialId.value) {
    credentialId.value = connections.value[0].id
    await load()
  }
}

async function load(): Promise<void> {
  if (!credentialId.value) return
  loading.value = true
  error.value = ''
  result.value = null
  try {
    result.value = await registryApi.browse(credentialId.value, path.value)
  } catch (e: unknown) {
    // 浏览**不静默** —— 用户主动点了一层，什么都不说等于页面坏了
    error.value = e instanceof Error ? e.message : '读取镜像目录失败'
  } finally {
    loading.value = false
  }
}

async function onConnectionChange(): Promise<void> {
  path.value = []
  await load()
}

async function drillInto(node: RegistryNode): Promise<void> {
  if (!node.hasChildren) return
  path.value = [...path.value, node.name]
  await load()
}

async function goTo(p: string[]): Promise<void> {
  path.value = [...p]
  await load()
}

async function copyImage(node: RegistryNode): Promise<void> {
  if (!node.copyText) return
  const ok = await writeClipboard(node.copyText)
  ElMessage[ok ? 'success' : 'warning'](ok ? '已复制镜像地址' : '当前浏览器不允许自动复制，请手动选中复制')
}

onMounted(loadConnections)
</script>

      这一层没有内容
    </div>
  </div>
</template>
```
