# 告警（S2.2）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让平台能管理 `PrometheusRule`、如实显示每条规则的运行状态、并接收 Alertmanager 推来的告警落库成可归属的列表。

**Architecture:** 三块互相独立，可分批上线。块 1 逐层照抄 ServiceMonitor 的 CRD 范式（`monitoring.coreos.com/v1`，走 fabric8 通用 CRD API + SSA + fetch-overlay）；块 2 在 platform-api 加一个只读 Prometheus 客户端，把 `/api/v1/rules` 的运行状态**附着**到块 1 的 DTO 上；块 3 是一个非用户身份的入站端点 + 一张追加型事件表 + 一个按租户收窄的列表。

**Tech Stack:** Spring Boot 4.1.1 / Java 21 / MyBatis / MySQL / fabric8 7.9.0 / Vue 3 + Element Plus + TypeScript

**Spec:** `docs/superpowers/specs/2026-10-17-alerting-design.md`

## Review Focus

以下是 spec 蕴含、但没有哪个任务的测试直接覆盖的失效场景，**最容易咬到用它的人**。每一条都在它归属的任务里有对应的测试。

1. **Alertmanager 重复投递同一批告警**（投递失败重试、`repeat_interval` 到点重推）—— 用户期望列表里**一次 firing 会话只有一行**，而不是每次重推多一行。→ Task 15
2. **命名空间和 CR 名同时含 `-`**（`my-app` + `rules`）—— 用户期望规则的运行状态**对得上它的规则**，而不是错配到别人的规则上。→ Task 11
3. **`labels.namespace` 缺失**（规则是 `kubectl apply` 建的、没经平台）—— 用户期望告警**照常出现在管理员的列表里**并标出「不属于任何租户」，而不是被丢弃或报 500。→ Task 15
4. **Prometheus 不可达 / 返回畸形 JSON** —— 用户期望**规则页照常能用**（CRUD 一切正常），只是运行状态显示「未知」，而不是整页 500。→ Task 10 + Task 12

```java
package com.coding.common.models.k8s.dto;

import com.coding.common.models.k8s.BaseResources;
import lombok.Data;
import lombok.EqualsAndHashCode;

import java.util.List;
import java.util.Map;

/**
 * PrometheusRule DTO（{@code monitoring.coreos.com/v1} CRD，**命名空间级**、租户域 —— 同 ServiceMonitor）。
 * <p>端点走 k8s-server {@code /prometheusrules}（{@code AbstractNamespacedResourceController} → 分配表三元组边界）。
 *
 * <h2>为什么必须 fetch-overlay</h2>
 * CRD 里 {@code spec.groups} 与 {@code group.rules} <b>都没有 listType 标记 → 默认 atomic</b>。
 * 对 atomic list，SSA 把整个列表当一个值拥有 —— 平台 apply 一次不带某个子字段，该子字段就被抹掉
 * （memory: fabric8-ssa-generic-crd 记的同一个坑；HTTPRoute 的 {@code spec.rules} 同形）。
 * 故 {@code PrometheusRuleConverter.convertForUpdate} 按 <b>组名</b> 与 <b>规则名</b> 对齐做 overlay。
 *
 * <p>本版**已建模全部已知字段**（{@code kubectl explain prometheusrule} 核对过），overlay 仍然要写：
 * 显式 round-trip 比依赖 schema 语义推断更可测，也对 CRD 版本漂移更稳健（同 GatewayConverter 的理由）。
 */
@Data
@EqualsAndHashCode(callSuper = true)
public class PrometheusRuleDTO extends BaseResources {

    /** spec.groups（必填，至少 1 组） */
    private List<Group> groups;

    /** 创建时间（仅查询返回，ISO-8601 字符串） */
    private String creationTime;

    /**
     * **这条规则在集群里跑得怎么样**（仅查询返回）—— 见 S2.2 块 2。
     *
     * <p>⚠️ 它**不是** K8s 对象的一部分：由 platform-api 读 Prometheus 的 {@code /api/v1/rules}
     * 后附着上来。拉不到就是 {@code null}，UI 显示「状态未知」，**CRUD 照常**。
     * converter 不映射本字段（它只在 list/get 的出站方向被填充）。
     */
    private RuleRuntime runtime;

    @Override
    public String getApiPath() {
        return "/prometheusrules";
    }

    /** spec.groups[] 项。字段全集来自 {@code kubectl explain prometheusrule.spec.groups}。 */
    @Data
    public static class Group {

        /** 组名（必填；同一 PrometheusRule 内唯一 —— overlay 的**对齐键**） */
        private String name;

        /** 求值间隔（如 30s） */
        private String interval;

        /** 规则求值时间戳的偏移（如 1m） */
        private String queryOffset;

        /** 一组告警/序列的产出上限（Prometheus ≥ 2.31） */
        private Integer limit;

        /** 组级标签（rule 级优先）；Prometheus ≥ 3.0，Thanos Ruler 忽略 */
        private Map<String, String> labels;

        /** 仅 ThanosRuler 用，Prometheus 忽略。本平台只读保留，不给编辑入口 */
        private String partialResponseStrategy;

        private List<Rule> rules;
    }

    /**
     * group.rules[] 项。字段全集来自 {@code kubectl explain prometheusrule.spec.groups.rules}。
     * <p>{@code alert} 与 {@code record} **恰好给一个**（CRD 约束，平台在 PrometheusRuleService 里前置拦截）。
     */
    @Data
    public static class Rule {

        /** 告警名（与 record 二选一）。overlay 的对齐键之一 */
        private String alert;

        /** 记录到的指标名（与 alert 二选一）。overlay 的对齐键之一 */
        private String record;

        /**
         * PromQL 表达式（必填）。
         * <p>⚠️ CRD 里是 {@code IntOrString} —— 上游允许裸数字（{@code expr: 1} 等价于 {@code vector(1)}）。
         * DTO 用 String；converter 读回来时把数字转成字符串，写出时按字符串写。
         */
        private String expr;

        /** 持续多久才算 firing（如 5m） */
        private String for_;

        /** 条件消失后继续 firing 多久（Prometheus ≥ 2.38） */
        private String keepFiringFor;

        private Map<String, String> labels;

        /** 仅 alert 规则有效 */
        private Map<String, String> annotations;
    }

    /**
     * 运行状态（仅查询返回）。{@code null} = 没探测或探测失败。
     * <p>三态判据见 {@code RuleRuntimeMatcher} 与 spec §6。
     */
    @Data
    public static class RuleRuntime {

        /** loaded = 在 /api/v1/rules 里对齐上了；missing = 没对齐上且过了宽限期；unknown = 拉不到 */
        private String loadState;

        /** 逐条规则的运行状态；loadState != loaded 时为空 */
        private List<RuleHealth> rules;
    }

    /** 单条规则的运行状态。键 (group, name) 与 {@link Group#getName()} / {@link Rule#getAlert()} 对齐。 */
    @Data
    public static class RuleHealth {

        /** spec.groups[].name */
        private String group;

        /** alert 的告警名 / record 的记录名 */
        private String name;

        /** ok | err | unknown */
        private String health;

        /** health=err 时 Prometheus 给的原文 */
        private String lastError;

        /** inactive | pending | firing；recording 规则恒为 null */
        private String state;

        /** 活跃告警数；recording 规则恒为 null */
        private Integer activeAlerts;
    }

}
```

> ⚠️ `for` 是 Java 关键字，字段名用 `for_`。**Jackson 序列化时会变成 `for_`** —— 前端与 converter 都按 `for_` 处理，不要额外加 `@JsonProperty`（本仓其它 DTO 也没这么做过，加了会在 JSON 里出现两个键）。

```java
package com.coding.k8score.converter.impl.monitoring;

import com.coding.common.models.k8s.dto.PrometheusRuleDTO;
import io.fabric8.kubernetes.api.model.GenericKubernetesResource;
import org.junit.jupiter.api.Test;

import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

import static org.assertj.core.api.Assertions.assertThat;

class PrometheusRuleConverterTest {

    private final PrometheusRuleConverter c = new PrometheusRuleConverter();

    private static PrometheusRuleDTO sample() {
        PrometheusRuleDTO dto = new PrometheusRuleDTO();
        dto.setName("app-rules");
        dto.setNamespace("my-app");

        PrometheusRuleDTO.Rule alert = new PrometheusRuleDTO.Rule();
        alert.setAlert("HighCPU");
        alert.setExpr("rate(container_cpu_usage_seconds_total[5m]) > 0.9");
        alert.setFor_("5m");
        alert.setLabels(Map.of("severity", "warning"));
        alert.setAnnotations(Map.of("summary", "CPU 高"));

        PrometheusRuleDTO.Rule record = new PrometheusRuleDTO.Rule();
        record.setRecord("job:http_errors:rate5m");
        record.setExpr("rate(http_requests_total{code=~\"5..\"}[5m])");

        PrometheusRuleDTO.Group g = new PrometheusRuleDTO.Group();
        g.setName("app");
        g.setInterval("30s");
        g.setRules(List.of(alert, record));

        dto.setGroups(List.of(g));
        return dto;
    }

    @Test
    void convert_produces_the_crd_shape() {
        GenericKubernetesResource res = c.convert(sample());

        assertThat(res.getApiVersion()).isEqualTo("monitoring.coreos.com/v1");
        assertThat(res.getKind()).isEqualTo("PrometheusRule");
        assertThat(res.getMetadata().getName()).isEqualTo("app-rules");
        assertThat(res.getMetadata().getNamespace()).isEqualTo("my-app");

        Map<String, Object> spec = spec(res);
        List<Map<String, Object>> groups = (List<Map<String, Object>>) spec.get("groups");
        assertThat(groups).hasSize(1);
        assertThat(groups.get(0).get("name")).isEqualTo("app");
        assertThat(groups.get(0).get("interval")).isEqualTo("30s");
        assertThat(groups.get(0)).doesNotContainKey("limit");      // null 不写出

        List<Map<String, Object>> rules = (List<Map<String, Object>>) groups.get(0).get("rules");
        assertThat(rules).hasSize(2);
        assertThat(rules.get(0)).containsEntry("alert", "HighCPU")
                .containsEntry("for", "5m")                        // ← 线上键名是 for，不是 for_
                .doesNotContainKey("record");
        assertThat(rules.get(1)).containsEntry("record", "job:http_errors:rate5m")
                .doesNotContainKey("alert");
    }

    /** 全字段 round-trip：反向不能丢任何建模字段。 */
    @Test
    void revert_round_trips_every_modeled_field() {
        PrometheusRuleDTO back = c.revert(c.convert(sample()));

        assertThat(back.getName()).isEqualTo("app-rules");
        PrometheusRuleDTO.Group g = back.getGroups().get(0);
        assertThat(g.getName()).isEqualTo("app");
        assertThat(g.getInterval()).isEqualTo("30s");
        assertThat(g.getRules()).hasSize(2);
        assertThat(g.getRules().get(0).getAlert()).isEqualTo("HighCPU");
        assertThat(g.getRules().get(0).getFor_()).isEqualTo("5m");
        assertThat(g.getRules().get(0).getLabels()).containsEntry("severity", "warning");
        assertThat(g.getRules().get(0).getAnnotations()).containsEntry("summary", "CPU 高");
        assertThat(g.getRules().get(1).getRecord()).isEqualTo("job:http_errors:rate5m");
    }

    /**
     * CRD 的 expr 是 IntOrString —— 上游允许裸数字（expr: 1 等价于 vector(1)）。
     * 读回来必须转成字符串，否则 round-trip 丢类型信息。
     */
    @Test
    void revert_converts_a_bare_numeric_expr_to_string() {
        GenericKubernetesResource res = new GenericKubernetesResource();
        res.setApiVersion("monitoring.coreos.com/v1");
        res.setKind("PrometheusRule");
        Map<String, Object> rule = new LinkedHashMap<>();
        rule.put("alert", "Always");
        rule.put("expr", 1);                                       // ← Integer，不是 String
        Map<String, Object> group = new LinkedHashMap<>();
        group.put("name", "g");
        group.put("rules", List.of(rule));
        res.setAdditionalProperty("spec", Map.of("groups", List.of(group)));

        PrometheusRuleDTO dto = c.revert(res);

        assertThat(dto.getGroups().get(0).getRules().get(0).getExpr()).isEqualTo("1");
    }

    /** 没有任何 group 时不能 NPE（空对象也是合法的 K8s 响应）。 */
    @Test
    void revert_tolerates_a_missing_spec() {
        GenericKubernetesResource res = new GenericKubernetesResource();
        res.setMetadata(new io.fabric8.kubernetes.api.model.ObjectMetaBuilder()
```

```java
import com.coding.common.models.k8s.dto.PrometheusRuleDTO;
import io.fabric8.kubernetes.api.model.GenericKubernetesResource;
import io.fabric8.kubernetes.api.model.ObjectMetaBuilder;

import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/**
 * PrometheusRuleDTO ⇄ GenericKubernetesResource（monitoring.coreos.com/v1 CRD）。
 *
 * <p>{@code spec.groups} 与 {@code group.rules} 都是 <b>atomic list</b> —— SSA 会把整个列表当一个值拥有。
 * 本类的 {@code convert} 用来建对象（无既有内容，直接覆盖即可）；**改对象必须走
 * {@link #convertForUpdate}**（按名对齐的 fetch-overlay），见那个方法的注释。
 */
public class PrometheusRuleConverter {

    public static final String API_VERSION = "monitoring.coreos.com/v1";

    /** spec.groups[] 的建模字段。overlay 时据此 set/clear；不在此列表的 key 视为外部字段，原样保留。 */
    private static final List<String> MODELED_GROUP_KEYS = List.of(
            "name", "interval", "queryOffset", "limit", "labels", "partialResponseStrategy", "rules");

    /** group.rules[] 的建模字段。 */
    private static final List<String> MODELED_RULE_KEYS = List.of(
            "alert", "record", "expr", "for", "keep_firing_for", "labels", "annotations");

    public GenericKubernetesResource convert(PrometheusRuleDTO dto) {
        GenericKubernetesResource res = new GenericKubernetesResource();
        res.setApiVersion(API_VERSION);
        res.setKind("PrometheusRule");
        res.setMetadata(new ObjectMetaBuilder()
                .withName(dto.getName())
                .withNamespace(dto.getNamespace())
                .withLabels(dto.getLabels())
                .build());

        Map<String, Object> spec = new LinkedHashMap<>();
        spec.put("groups", toGroupMaps(dto.getGroups()));   // 必填：空也给空数组
        res.setAdditionalProperty("spec", spec);
        return res;
    }

    @SuppressWarnings("unchecked")
    public PrometheusRuleDTO revert(GenericKubernetesResource res) {
        PrometheusRuleDTO dto = new PrometheusRuleDTO();
        if (res == null) {
            return dto;
        }
        if (res.getMetadata() != null) {
            dto.setName(res.getMetadata().getName());
            dto.setNamespace(res.getMetadata().getNamespace());
            dto.setLabels(res.getMetadata().getLabels());
            if (res.getMetadata().getCreationTimestamp() != null) {
                dto.setCreationTime(res.getMetadata().getCreationTimestamp());
            }
        }
        Map<String, Object> spec = res.getAdditionalProperties() != null
                ? (Map<String, Object>) res.getAdditionalProperties().get("spec") : null;
        if (spec == null) {
            return dto;
        }
        dto.setGroups(fromGroupMaps(spec.get("groups")));
        return dto;
    }

    // ---------- 模型 → Map ----------

    private List<Map<String, Object>> toGroupMaps(List<PrometheusRuleDTO.Group> groups) {
        if (groups == null) {
            return List.of();
        }
        List<Map<String, Object>> out = new ArrayList<>();
        for (PrometheusRuleDTO.Group g : groups) {
            Map<String, Object> m = new LinkedHashMap<>();
            putStr(m, "name", g.getName());
            putStr(m, "interval", g.getInterval());
            putStr(m, "queryOffset", g.getQueryOffset());
            if (g.getLimit() != null) {
                m.put("limit", g.getLimit());
            }
            if (g.getLabels() != null && !g.getLabels().isEmpty()) {
                m.put("labels", g.getLabels());
            }
            putStr(m, "partialResponseStrategy", g.getPartialResponseStrategy());
            m.put("rules", toRuleMaps(g.getRules()));
            out.add(m);
        }
        return out;
    }

    private List<Map<String, Object>> toRuleMaps(List<PrometheusRuleDTO.Rule> rules) {
        if (rules == null) {
            return List.of();
        }
        List<Map<String, Object>> out = new ArrayList<>();
        for (PrometheusRuleDTO.Rule r : rules) {
            Map<String, Object> m = new LinkedHashMap<>();
            putStr(m, "alert", r.getAlert());
            putStr(m, "record", r.getRecord());
            putStr(m, "expr", r.getExpr());          // 始终 String 写出（线上允许数字，但字符串总是合法的）
            putStr(m, "for", r.getFor_());            // ← Java 字段名 for_，线上键名 for
            putStr(m, "keep_firing_for", r.getKeepFiringFor());
            if (r.getLabels() != null && !r.getLabels().isEmpty()) {
                m.put("labels", r.getLabels());
            }
            if (r.getAnnotations() != null && !r.getAnnotations().isEmpty()) {
                m.put("annotations", r.getAnnotations());
            }
            out.add(m);
        }
        return out;
    }

    // ---------- Map → 模型 ----------

    @SuppressWarnings("unchecked")
    private List<PrometheusRuleDTO.Group> fromGroupMaps(Object raw) {
        if (!(raw instanceof List<?> list)) {
            return null;
        }
        List<PrometheusRuleDTO.Group> out = new ArrayList<>();
        for (Object o : list) {
            if (!(o instanceof Map)) {
                continue;
            }
            Map<String, Object> m = (Map<String, Object>) o;
            PrometheusRuleDTO.Group g = new PrometheusRuleDTO.Group();
            g.setName(asStr(m.get("name")));
            g.setInterval(asStr(m.get("interval")));
            g.setQueryOffset(asStr(m.get("queryOffset")));
            g.setLimit(asInt(m.get("limit")));
            g.setLabels(asStringMap(m.get("labels")));
            g.setPartialResponseStrategy(asStr(m.get("partialResponseStrategy")));
            g.setRules(fromRuleMaps(m.get("rules")));
            out.add(g);
        }
        return out;
    }

    @SuppressWarnings("unchecked")
    private List<PrometheusRuleDTO.Rule> fromRuleMaps(Object raw) {
        if (!(raw instanceof List<?> list)) {
            return null;
        }
        List<PrometheusRuleDTO.Rule> out = new ArrayList<>();
        for (Object o : list) {
            if (!(o instanceof Map)) {
                continue;
            }
            Map<String, Object> m = (Map<String, Object>) o;
            PrometheusRuleDTO.Rule r = new PrometheusRuleDTO.Rule();
            r.setAlert(asStr(m.get("alert")));
            r.setRecord(asStr(m.get("record")));
            r.setExpr(asStr(m.get("expr")));          // ⚠️ 裸数字也要转成串，见测试
            r.setFor_(asStr(m.get("for")));
            r.setKeepFiringFor(asStr(m.get("keep_firing_for")));
            r.setLabels(asStringMap(m.get("labels")));
            r.setAnnotations(asStringMap(m.get("annotations")));
            out.add(r);
        }
        return out;
    }

    // ---------- update：按名对齐的 fetch-overlay（Task 3 实现） ----------

    /** update 专用占位，Task 3 填实现。 */
    public GenericKubernetesResource convertForUpdate(PrometheusRuleDTO dto, GenericKubernetesResource live) {
        return convert(dto);
    }

    // ---------- 辅助 ----------

    static void putStr(Map<String, Object> m, String key, String v) {
        if (v != null && !v.isBlank()) {
            m.put(key, v);
        }
    }

    /**
     * 读成字符串。**数字也要转** —— CRD 的 {@code expr} 是 IntOrString，
     * 线上真的有 {@code expr: 1} 这种写法，不转就丢类型信息。
     */
    static String asStr(Object o) {
        return o == null ? null : String.valueOf(o);
    }

    static Integer asInt(Object o) {
        if (o instanceof Number n) {
            return n.intValue();
        }
        if (o instanceof String s && !s.isBlank()) {
            try {
                return Integer.valueOf(s);
            } catch (NumberFormatException ignored) {
                return null;
            }
        }
        return null;
    }

    @SuppressWarnings("unchecked")
    static Map<String, String> asStringMap(Object o) {
        if (!(o instanceof Map)) {
            return null;
        }
        Map<String, String> out = new LinkedHashMap<>();
        ((Map<Object, Object>) o).forEach((k, v) -> out.put(String.valueOf(k), v == null ? null : String.valueOf(v)));
        return out.isEmpty() ? null : out;
    }

    /**
     * 规则的**对齐键**：alert 名或 record 名（CRD 要求同一组内唯一）。
     * <p>Task 3 的 overlay 与 Task 11 的运行状态匹配都用它 —— 两处必须是同一个定义，故是 public static。
     */
    public static String ruleKey(PrometheusRuleDTO.Rule r) {
        if (r == null) {
            return "";
        }
        return r.getAlert() != null && !r.getAlert().isBlank() ? "alert:" + r.getAlert()
                : r.getRecord() != null && !r.getRecord().isBlank() ? "record:" + r.getRecord()
                : "";
    }

}
```

```java
    /**
     * update 专用：{@code spec.groups} 与 {@code group.rules} 都是 atomic list，
     * SSA 重声明会丢弃未建模子字段。故以线上对象为底，**按组名 / 规则名对齐**后逐项覆盖建模字段。
     *
     * <p><b>为什么按名而不是按 index</b>（ServiceMonitor 用的是 index）：组名与规则名在 CRD 里
     * 本来就是唯一键，用户重排、插入、删除都不会错位 —— 而 index 对齐在"中间插一条"时会
     * 把后面所有元素的未建模字段串到错误的对象上。
     *
     * <p>对齐不上的（用户新加的）→ 全新构建；线上有而本次没带的（用户删掉的）→ 丢弃。
     */
    @SuppressWarnings("unchecked")
    public GenericKubernetesResource convertForUpdate(PrometheusRuleDTO dto, GenericKubernetesResource live) {
        GenericKubernetesResource res = convert(dto);
        Map<String, Object> liveSpec = live != null && live.getAdditionalProperties() != null
                ? (Map<String, Object>) live.getAdditionalProperties().get("spec") : null;
        Map<String, Map<String, Object>> liveGroups = indexByName(readList(liveSpec, "groups"), "name");

        List<Map<String, Object>> merged = new ArrayList<>();
        for (PrometheusRuleDTO.Group g : (dto.getGroups() != null ? dto.getGroups() : List.<PrometheusRuleDTO.Group>of())) {
            Map<String, Object> base = liveGroups.get(g.getName());
            merged.add(overlayGroup(base, g));
        }
        Map<String, Object> spec = (Map<String, Object>) res.getAdditionalProperties().get("spec");
        if (spec != null) {
            spec.put("groups", merged);
        }
        return res;
    }

    /** 以 base（线上组）为底，仅覆盖建模字段；未建模 key 保留。rules 单独按规则名对齐。 */
    private Map<String, Object> overlayGroup(Map<String, Object> base, PrometheusRuleDTO.Group g) {
        Map<String, Object> dtoGroup = toGroupMaps(List.of(g)).get(0);
        Map<String, Object> out = base != null ? new LinkedHashMap<>(base) : new LinkedHashMap<>();
        for (String key : MODELED_GROUP_KEYS) {
            if ("rules".equals(key)) {
                continue;                       // rules 单独处理
            }
            if (dtoGroup.containsKey(key)) {
                out.put(key, dtoGroup.get(key));
            } else {
                out.remove(key);                // 用户清空该字段 → 从对象移除
            }
        }
        Map<String, Map<String, Object>> liveRules =
                indexByName(readList(base, "rules"), PrometheusRuleConverter::ruleKeyOf);
        List<Map<String, Object>> mergedRules = new ArrayList<>();
        for (PrometheusRuleDTO.Rule r : (g.getRules() != null ? g.getRules() : List.<PrometheusRuleDTO.Rule>of())) {
            mergedRules.add(overlayRule(liveRules.get(ruleKey(r)), r));
        }
        out.put("rules", mergedRules);
        return out;
    }

    /** 以 base（线上规则）为底，仅覆盖建模字段；未建模 key 保留。 */
    private Map<String, Object> overlayRule(Map<String, Object> base, PrometheusRuleDTO.Rule r) {
        Map<String, Object> dtoRule = toRuleMaps(List.of(r)).get(0);
        Map<String, Object> out = base != null ? new LinkedHashMap<>(base) : new LinkedHashMap<>();
        for (String key : MODELED_RULE_KEYS) {
            if (dtoRule.containsKey(key)) {
                out.put(key, dtoRule.get(key));
            } else {
                out.remove(key);
            }
        }
        return out;
    }

    @SuppressWarnings("unchecked")
    private static List<Map<String, Object>> readList(Map<String, Object> holder, String key) {
        if (holder == null || !(holder.get(key) instanceof List<?> list)) {
            return List.of();
        }
        List<Map<String, Object>> out = new ArrayList<>();
        for (Object o : list) {
            if (o instanceof Map) {
                out.add((Map<String, Object>) o);
            }
        }
        return out;
    }

    /** 把线上的一串 Map 按某个键索引起来（键为空则跳过该元素）。 */
    private static Map<String, Map<String, Object>> indexByName(
            List<Map<String, Object>> items, java.util.function.Function<Map<String, Object>, String> keyFn) {
        Map<String, Map<String, Object>> out = new LinkedHashMap<>();
        for (Map<String, Object> m : items) {
            String k = keyFn.apply(m);
            if (k != null && !k.isBlank()) {
                out.put(k, m);                  // 同名只留最后一个 —— CRD 本就要求唯一，这里只是不炸
            }
        }
        return out;
    }

    /** 线上规则 Map 的对齐键：与 {@link #ruleKey} 同一套前缀，两处共用一个定义。 */
    static String ruleKeyOf(Map<String, Object> m) {
        String alert = asStr(m.get("alert"));
        if (alert != null && !alert.isBlank()) {
            return "alert:" + alert;
        }
        String record = asStr(m.get("record"));
        return record != null && !record.isBlank() ? "record:" + record : "";
    }
```

```java
package com.coding.platformapi.services;

import com.coding.common.exception.CloudPlatformException;
import com.coding.common.exception.EnumResponseType;
import com.coding.common.models.k8s.dto.PrometheusRuleDTO;
import com.coding.platformapi.k8s.K8sClient;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.util.StringUtils;

import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/**
 * PrometheusRule 业务层。与 ServiceMonitorService 一样是透传 —— 只多**一条**本平台自己的规则。
 *
 * <p><b>代打 {@code labels.namespace}</b>：Alertmanager 推到平台的 payload 里没有
 * 「这条规则是谁建的」这个字段，{@code labels.namespace} 是唯一能带过来的归属线索，
 * 而它是**规则作者自己填的**、不可信。平台在下发时覆写它，是唯一能保证归属可信的写法
 * （见 docs/superpowers/specs/2026-10-17-alerting-design.md 决策 5）。
 *
 * <p>只打 {@code alert} 规则：{@code record} 规则不产生告警，给它打 namespace 只会污染指标标签。
 */
@Service
@RequiredArgsConstructor
public class PrometheusRuleService {

    private final K8sClient k8s;

    public List<PrometheusRuleDTO> list(PrometheusRuleDTO query) {
        return k8s.list(query);
    }

    public PrometheusRuleDTO get(String name, String tenantId, String clusterId, String namespace) {
        return k8s.get(dto(name, tenantId, clusterId, namespace));
    }

    public String yaml(String name, String tenantId, String clusterId, String namespace) {
        return k8s.yaml(dto(name, tenantId, clusterId, namespace));
    }

    public PrometheusRuleDTO create(PrometheusRuleDTO body) {
        stampNamespace(body);
        return k8s.create(body);
    }

    public PrometheusRuleDTO update(PrometheusRuleDTO body) {
        stampNamespace(body);
        return k8s.update(body);
    }

    public void delete(String name, String tenantId, String clusterId, String namespace) {
        k8s.delete(dto(name, tenantId, clusterId, namespace));
    }

    /**
     * 内容校验 + 代打 namespace 标。
     * <p>校验放在这里而不是让 K8s API server 拒：后者的报错是
     * {@code must be specified} 这种，用户不知道该改哪儿。
     */
    private void stampNamespace(PrometheusRuleDTO body) {
        if (body.getGroups() == null || body.getGroups().isEmpty()) {
            throw new CloudPlatformException(EnumResponseType.PROMETHEUS_RULE_INVALID,
                    "至少需要一组规则（groups）。");
        }
        for (PrometheusRuleDTO.Group g : body.getGroups()) {
            if (!StringUtils.hasText(g.getName())) {
                throw new CloudPlatformException(EnumResponseType.PROMETHEUS_RULE_INVALID,
                        "每一组都要有组名（groups[].name）。");
            }
            if (g.getRules() == null || g.getRules().isEmpty()) {
                throw new CloudPlatformException(EnumResponseType.PROMETHEUS_RULE_INVALID,
                        "组「" + g.getName() + "」里没有规则。");
            }
            for (PrometheusRuleDTO.Rule r : g.getRules()) {
                boolean hasAlert = StringUtils.hasText(r.getAlert());
                boolean hasRecord = StringUtils.hasText(r.getRecord());
                if (hasAlert == hasRecord) {
                    throw new CloudPlatformException(EnumResponseType.PROMETHEUS_RULE_INVALID,
                            "组「" + g.getName() + "」里有一条规则 alert 与 record "
                                    + (hasAlert ? "同时给了 —— 只能给一个。" : "都没给 —— 必须给一个。"));
                }
                if (!StringUtils.hasText(r.getExpr())) {
                    throw new CloudPlatformException(EnumResponseType.PROMETHEUS_RULE_INVALID,
                            "组「" + g.getName() + "」里的规则「"
                                    + (hasAlert ? r.getAlert() : r.getRecord()) + "」没有表达式（expr）。");
                }
                if (hasAlert) {
                    // 以平台的为准：先复制用户那份，再覆写 namespace（不动其它标签）
```

```java
package com.coding.platformapi.metrics;

import com.coding.common.models.k8s.dto.PrometheusRuleDTO;

import java.time.Duration;
import java.time.Instant;
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/**
 * 把 Prometheus {@code /api/v1/rules} 的规则**对齐**到平台手上的 PrometheusRule 对象。
 *
 * <h2>为什么不能解析 file</h2>
 * prometheus-operator 把每条 CR 渲染成一个文件，路径形如
 * {@code …/rulefiles-0/<namespace>-<CR名>-<uuid>.yaml}。看起来能切，但**命名空间和 CR 名都含 `-`**：
 * <pre>
 *   monitor-ps-kube-prometheus-stack-alertmanager.rules-&lt;uuid&gt;   按第一个 - 切：ns=monitor ✓
 *   my-app-rules-&lt;uuid&gt;                                          按第一个 - 切：ns=my      ✗
 * </pre>
 * 正确做法是**拿平台手上的 (namespace, CR名) 清单去匹配**那些 file —— 永远在一个已知候选集里对，
 * 不存在切错的可能。同名互为前缀的（{@code a} + {@code b-c} vs {@code a-b} + {@code c}）也不会串。
 *
 * <h2>宽限期</h2>
 * 规则刚建时 Prometheus 还没 reload（prometheus-operator 有延迟），此时"找不到"是**正常**的，
 * 不能报 missing。过了宽限期还找不到，才说明它真的没被拾取 —— 那正是本功能要暴露的那件事。
 */
public final class RuleRuntimeMatcher {

    private RuleRuntimeMatcher() {
    }

    /** 规则文件名的前缀：{@code <ns>-<CR名>-}。够长了，不会和别人的前缀撞上（尾部必须是 `-`）。 */
    private static String filePrefix(PrometheusRuleDTO r) {
        return r.getNamespace() + "-" + r.getName() + "-";
    }

    /**
     * @param groups        Prometheus 返回的规则组（{@link PromRulesClient#groups}）
     * @param rules         本次 list/get 拿到的 PrometheusRule 对象
     * @param grace         宽限期（未过期就不报 missing）
     * @return              附着到 DTO 上的运行状态；一个都没对齐上且过了宽限期 → {@code missing}
     */
    public static PrometheusRuleDTO.RuleRuntime match(
            List<PromRulesClient.RuleGroup> groups, List<PrometheusRuleDTO> rules, Duration grace) {

        // 候选文件名前缀 → CR。**一个前缀可能对上多份** —— 见 matchByFilePrefix 的注释。
        Map<String, List<PrometheusRuleDTO>> byPrefix = new LinkedHashMap<>();
        for (PrometheusRuleDTO r : rules) {
            if (r.getNamespace() != null && r.getName() != null) {
                byPrefix.computeIfAbsent(filePrefix(r), k -> new ArrayList<>()).add(r);
            }
        }

        // 有任何一个前缀对上多份 → 整份 unknown。宁可说"对不上账"，也不猜。
        for (List<PrometheusRuleDTO> candidates : byPrefix.values()) {
            if (candidates.size() > 1) {
                PrometheusRuleDTO.RuleRuntime ambiguous = new PrometheusRuleDTO.RuleRuntime();
                ambiguous.setLoadState("unknown");
                ambiguous.setRules(List.of());
                return ambiguous;
            }
        }

        // group.file → 平台认定的 CR（只有前缀匹配上的才算）
        Map<PromRulesClient.RuleGroup, PrometheusRuleDTO> owner = new LinkedHashMap<>();
        boolean anyMatched = false;
        for (PromRulesClient.RuleGroup g : groups) {
            PrometheusRuleDTO cr = matchByFilePrefix(g.file(), byPrefix);
            if (cr != null) {
                owner.put(g, cr);
                anyMatched = true;
            }
        }

        PrometheusRuleDTO.RuleRuntime rt = new PrometheusRuleDTO.RuleRuntime();
        if (!anyMatched && !isWithinGrace(rules, grace)) {
            rt.setLoadState("missing");
            rt.setRules(List.of());
            return rt;
        }
        rt.setLoadState("loaded");

        // 逐条规则附着：先按 (CR, group名) 建索引，再按规则名取
        Map<String, Map<String, PromRulesClient.RuleView>> index = new LinkedHashMap<>();
        for (Map.Entry<PromRulesClient.RuleGroup, PrometheusRuleDTO> e : owner.entrySet()) {
            PromRulesClient.RuleGroup g = e.getKey();
            String key = crGroupKey(e.getValue(), g.name());
            Map<String, PromRulesClient.RuleView> byName = new LinkedHashMap<>();
            for (PromRulesClient.RuleView v : g.rules()) {
                byName.put(v.name(), v);
            }
            index.merge(key, byName, (a, b) -> { a.putAll(b); return a; });
        }

        List<PrometheusRuleDTO.RuleHealth> out = new ArrayList<>();
        for (PrometheusRuleDTO cr : rules) {
            for (PrometheusRuleDTO.Group g : (cr.getGroups() != null ? cr.getGroups() : List.<PrometheusRuleDTO.Group>of())) {
                Map<String, PromRulesClient.RuleView> byName = index.get(crGroupKey(cr, g.getName()));
                for (PrometheusRuleDTO.Rule r : (g.getRules() != null ? g.getRules() : List.<PrometheusRuleDTO.Rule>of())) {
                    String name = r.getAlert() != null && !r.getAlert().isBlank() ? r.getAlert() : r.getRecord();
                    PromRulesClient.RuleView v = byName != null ? byName.get(name) : null;
                    PrometheusRuleDTO.RuleHealth h = new PrometheusRuleDTO.RuleHealth();
                    h.setGroup(g.getName());
                    h.setName(name);
                    if (v == null) {
                        h.setHealth("unknown");
                    } else {
                        h.setHealth(v.health() != null ? v.health() : "unknown");
                        h.setLastError(v.lastError());
                        h.setState(v.state());
                        h.setActiveAlerts(v.activeAlerts());
                    }
                    out.add(h);
                }
            }
        }
        rt.setRules(out);
        return rt;
    }

    /**
     * 在候选集里找前缀匹配的 CR。用 {@code contains("/" + prefix)} 而不是 split —— 见类注释。
     *
     * <p><b>前导斜杠是必须的</b>：file 是绝对路径，前缀前面必有 `/`。去掉它 `a-b-` 会匹配到
     * `xa-b-c-…`。而**歧义**（一个前缀对上多份）由调用方在进入本方法前就已经排除掉了。
     */
    private static PrometheusRuleDTO matchByFilePrefix(String file, Map<String, List<PrometheusRuleDTO>> byPrefix) {
        if (file == null) {
            return null;
        }
        for (Map.Entry<String, List<PrometheusRuleDTO>> e : byPrefix.entrySet()) {
            if (file.contains("/" + e.getKey())) {
                return e.getValue().get(0);
            }
        }
        return null;
    }

    /**
     * 宽限期判断：**只要有一条 CR 还在宽限期内**就不报 missing。
     * <p>creationTime 解析不了时按"老对象"处理 —— 宁可报 missing 也别静默放过。
     */
    private static boolean isWithinGrace(List<PrometheusRuleDTO> rules, Duration grace) {
        if (rules.isEmpty()) {
            return true;               // 没有对象可谈，谈不上 missing
        }
        Instant now = Instant.now();
        for (PrometheusRuleDTO r : rules) {
            try {
                Instant created = Instant.parse(r.getCreationTime());
                if (Duration.between(created, now).compareTo(grace) < 0) {
                    return true;
                }
            } catch (Exception ignored) {
                // 解析不了 → 视为老对象，不救
            }
        }
        return false;
    }

    private static String crGroupKey(PrometheusRuleDTO cr, String groupName) {
        return cr.getNamespace() + "/" + cr.getName() + "#" + groupName;
    }

}
```

> ⚠️ `matchByFilePrefix` 用 `contains("/" + prefix)`（带前导斜杠）而不是裸 `startsWith` —— file 是**绝对路径**，前缀前面必有 `/`。这样 `a-b-c-<uuid>.yaml` 不会被 `a-` 这种短前缀误匹配。**前导斜杠是必须的**，去掉它 `a-b` + `c` 就会匹配到 `xa-b-c-...`。

```java
    private final K8sClient k8s;
    private final K8sClusterMapper clusterMapper;      // 取 prometheusUrl
    private final PromRulesClient promRules;

    /** 规则刚建、Prometheus 还没 reload 的宽限期。覆盖 prometheus-operator 的 reload 延迟。 */
    private static final Duration LOAD_GRACE = Duration.ofMinutes(5);

    public List<PrometheusRuleDTO> list(PrometheusRuleDTO query) {
        List<PrometheusRuleDTO> out = k8s.list(query);
        enrich(out, query.getClusterId());
        return out;
    }

    public PrometheusRuleDTO get(String name, String tenantId, String clusterId, String namespace) {
        PrometheusRuleDTO out = k8s.get(dto(name, tenantId, clusterId, namespace));
        if (out != null) {
            enrich(List.of(out), clusterId);
        }
        return out;
    }

    /**
     * 附着运行状态。**整个 list 只打 Prometheus 一次**（一次响应可能有几百 KB，
     * 不能按规则条数打）。任何失败都降级成"不附着"，**绝不让它影响 CRUD**
     * —— 与 ServiceMonitorService 的 relabelLabels/metricNames 同一口径。
     */
    private void enrich(List<PrometheusRuleDTO> rules, String clusterId) {
        if (rules == null || rules.isEmpty() || !StringUtils.hasText(clusterId)) {
            return;
        }
        K8sCluster cluster = clusterMapper.selectByPrimaryKey(clusterId);
        if (cluster == null || !StringUtils.hasText(cluster.getPrometheusUrl())) {
            return;                                     // 没配就不探，与 SM/PM 同口径
        }
        String base = cluster.getPrometheusUrl().replaceAll("/+$", "");
        try {
            List<PromRulesClient.RuleGroup> groups = promRules.groups(base);
            for (PrometheusRuleDTO r : rules) {
                r.setRuntime(RuleRuntimeMatcher.match(groups, List.of(r), LOAD_GRACE));
            }
        } catch (Exception e) {
            log.warn("拉取 Prometheus 规则状态失败（cluster={}）: {}", clusterId, e.getMessage());
        }
    }
```

> ⚠️ 注意 `match` 的第二个参数是**单元素的 list**：契约是「一个 CR 一份 runtime」，而 `match` 的 missing 判定要看这个 CR 自己的 `creationTime`。如果传整个 list，一条老规则的 missing 会连累新规则。**逐条传**。

- [ ] **Step 4: 写 ingest service**

要点（照 spec §7.2 / §10）：

```java
    /** 落库。返回**实际成功条数**。单条失败不中断整批（Alertmanager 只看状态码）。 */
    public int ingest(String clusterId, List<AlertWebhookRequest.Alert> alerts) {
        if (alerts == null || alerts.isEmpty()) {
            return 0;
        }
        int ok = 0;
        for (AlertWebhookRequest.Alert a : alerts) {
            try {
                PlatformAlertEvent row = toRow(clusterId, a);
                if (row == null) {
                    continue;                          // alertname 缺失等 —— 记 warn 后跳过
                }
                mapper.upsert(row);
                ok++;
            } catch (Exception e) {
                log.error("告警落库失败（cluster={} alertname={}）",
                        clusterId, a.getLabels() != null ? a.getLabels().get("alertname") : null, e);
            }
        }
        return ok;
    }
```

`toRow` 里：

1. `labels` / `annotations` 用 `JsonMapper` 序列化成字符串（JSON 列）。
2. `namespace` 取 `labels.get("namespace")`，**空串归一成 null**。
3. `namespace` 非空时调 `allocs.selectByClusterAndNs(clusterId, ns)` 校验；**返回空只记 warn**，照常落库。
4. `startsAt` / `endsAt` 用 `OffsetDateTime.parse(...)` 再 `toInstant()`，**截到毫秒**（`Instant.truncatedTo(ChronoUnit.MILLIS)`）。解析失败：`startsAt` 缺了就跳过该条（幂等键不全，写进去会产生重复行）；`endsAt` 缺了置 null。
5. `receivedAt = new Date()`，同样截到毫秒。
6. `alertname` 为空 → 记 warn 返回 null。

> ### ⚠️ 本任务的第一个坑：业务异常回 200，而 Alertmanager 只看状态码
>
> 本仓的 `GlobalExceptionHandler` 对 `CloudPlatformException` **没有 `@ResponseStatus`** ——
> 业务异常一律回 **HTTP 200** + body 里的错误码（其余端点都这么用，前端按 code 判断）。
>
> **但 Alertmanager 不看 body。** 密钥错了若回 200，它会认为投递成功、**把告警丢掉** ——
> 那是最坏的一种静默失败，而且完全无声（集群侧日志里连一条重试都没有）。
>
> 所以本端点**不能借道 `CloudPlatformException` 的默认映射**，必须回真状态码。
> 做法：**控制器直接返回 `ResponseEntity`，并把请求体收成 `String` 自己解析** ——
> 这样三种失败模式（鉴权、解析、落库）各自的状态码都由本类说了算，
> 不用去和全局异常处理器较劲（它那条 `HttpMessageNotReadableException` 分支**也是回 200 的**）。

```java
package com.coding.platformapi.config;

import jakarta.annotation.PostConstruct;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;
import org.springframework.util.StringUtils;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;

/**
 * Alertmanager webhook 的共享密钥。
 *
 * <p>{@code /alert/webhook} 是平台**第一个非用户身份的入站端点** —— 它不是某个登录用户调的，
 * 没有 JWT，所以既进 {@link com.coding.platformapi.security.ExemptPaths}（跳过 JWT 鉴权），
 * 又必须自校验一个共享密钥。
 *
 * <p><b>密钥没配就拒启</b>（fail-closed）—— 理由同 PermissionCrossCheckRunner：
 * 一个"忘了配就等于全开"的入站端点不该存在。宁可起不来。
 */
@Slf4j
@Component
public class AlertWebhookTokenCheck {

    private final String token;

    public AlertWebhookTokenCheck(@Value("${platform.alert.webhook.token:}") String token) {
        this.token = token;
    }

    @PostConstruct
    void requireConfigured() {
        if (!StringUtils.hasText(token)) {
            throw new IllegalStateException(
                    "platform.alert.webhook.token 未配置 —— /alert/webhook 是公开可达的入站端点，"
                            + "没有密钥就等于全开。请配置 ALERT_WEBHOOK_TOKEN 后重启。");
        }
        log.info("告警接收端点已启用（共享密钥已配置）");
    }

    /** 常量时间比较，避免按字符泄时。带不带 {@code Bearer } 前缀都认。 */
    public boolean matches(String presented) {
        if (presented == null) {
            return false;
        }
        String v = presented.startsWith("Bearer ") ? presented.substring(7) : presented;
        return MessageDigest.isEqual(v.getBytes(StandardCharsets.UTF_8), token.getBytes(StandardCharsets.UTF_8));
    }
}
```

```java
import lombok.extern.slf4j.Slf4j;

import org.springframework.http.ResponseEntity;
import org.springframework.util.StringUtils;
import org.springframework.web.bind.annotation.PostMapping;

import tools.jackson.databind.json.JsonMapper;

/**
 * Alertmanager 的告警推送入口。
 *
 * <h2>⚠️ 为什么这个控制器不走本仓的常规异常路线</h2>
 * 本仓的 {@code GlobalExceptionHandler} 对 {@code CloudPlatformException} 一律回 **HTTP 200**
 * 加 body 里的错误码 —— 其余端点都这么用，前端按 code 判断。**但 Alertmanager 只看状态码**：
 * 它收到 2xx 就认为投递成功，不会重试、不会有任何异常痕迹。密钥错了回 200 = **告警被静默丢掉**。
 *
 * <p>所以本类**直接返回 {@link ResponseEntity}**，并且把请求体收成 {@code String} 自己解析
 * （否则畸形 JSON 会被全局处理器的 {@code HttpMessageNotReadableException} 分支当成 200 吞掉）。
 * 三种失败模式的状态码全部由本类说了算：
 *
 * <ul>
 *   <li>密钥不对 → <b>401</b></li>
 *   <li>体解析失败 / clusterId 缺失 → <b>400</b></li>
 *   <li>落库内部异常 → <b>200</b>（重试不会变好，只会放大）</li>
 * </ul>
 */
@Slf4j
@Tag(name = "告警", description = "Alertmanager webhook 接收")
@RestController
@RequestMapping("/alert")
@RequiredArgsConstructor
public class AlertWebhookController {

    private final AlertIngestService ingest;
    private final AlertWebhookTokenCheck tokenCheck;

    private final JsonMapper jsonMapper = JsonMapper.builder().build();

    @PostMapping("/webhook")
    @Operation(summary = "接收 Alertmanager 的告警推送（共享密钥鉴权；真实状态码）")
    public ResponseEntity<ResponseData<Map<String, Integer>>> webhook(
            @RequestHeader(value = "Authorization", required = false) String authorization,
            @RequestParam(required = false) String clusterId,
            @RequestBody(required = false) String rawBody) {

        if (!tokenCheck.matches(authorization)) {
            log.warn("告警接收端点鉴权失败（Authorization {}）",
                    authorization == null ? "缺失" : "不匹配");
            return ResponseEntity.status(HttpStatus.UNAUTHORIZED)
                    .body(new ResponseData<>(EnumResponseType.ALERT_WEBHOOK_UNAUTHORIZED.getCode(),
                            "告警接收端点鉴权失败。", null));
        }
        if (!StringUtils.hasText(clusterId)) {
            log.warn("告警推送缺少 clusterId 查询参数 —— 集群侧 receiver 的 url 配错了。");
            return ResponseEntity.badRequest()
                    .body(new ResponseData<>(EnumResponseType.INVALID_FORMAT_FAIL.getCode(),
                            "缺少 clusterId 查询参数（写在 receiver 的 url 里，如 ?clusterId=xxx）。", null));
        }

        List<AlertWebhookRequest.Alert> alerts;
        try {
            JavaType type = jsonMapper.getTypeFactory()
                    .constructCollectionType(List.class, AlertWebhookRequest.Alert.class);
            alerts = jsonMapper.readValue(rawBody == null ? "" : rawBody, type);
        } catch (Exception e) {
            log.warn("告警推送的请求体解析失败：{}", e.getMessage());
            return ResponseEntity.badRequest()
                    .body(new ResponseData<>(EnumResponseType.INVALID_FORMAT_FAIL.getCode(),
                            "请求体不是 Alertmanager 的告警数组。", null));
        }

        int accepted;
        try {
            accepted = ingest.ingest(clusterId, alerts);
        } catch (Exception e) {
            // 仍然回 200：Alertmanager 只看状态码，重投一次也不会好，只会放大。
            log.error("告警落库整体失败（cluster={}）", clusterId, e);
            accepted = 0;
        }
        return ResponseEntity.ok(new ResponseData<>(Map.of("accepted", accepted)));
    }
}
```

**`clusterId` 从哪来** —— 这是本任务必须定死的一件事：

1. **URL 查询参数**：Alertmanager 的 `url` 里带上 `?clusterId=xxx`。
2. payload 的 externalLabels：Alertmanager 的 webhook payload **不含**这个。
3. 配置项 `platform.alert.webhook.cluster-id`（只适合单集群平台）。

**采用 (1)**，理由：平台是纳管多集群的，写死在配置里就不对了；URL 参数是 Alertmanager 天然能带的东西，
而且**一个集群配一个 receiver** 本来就该分得清。缺失时回 400（配错了要能看出来，不能默默归到某个默认集群）。

> ⚠️ `INVALID_FORMAT_FAIL` 是本仓既有的码 —— **打开 `EnumResponseType` 确认它存在**；不存在就用 `ERROR`。

```java
    private static final int MAX_LIMIT = 200;

    public List<PlatformAlertEvent> list(AlertQueryRequest req) {
        PlatformAlertEventQuery q = new PlatformAlertEventQuery();
        q.setClusterId(req.getClusterId());
        q.setFrom(req.getFrom());
        q.setTo(req.getTo());
        q.setNamespace(req.getNamespace());
        q.setStatus(req.getStatus());
        q.setSeverity(req.getSeverity());
        q.setAlertname(req.getAlertname());
        q.setExcludeWatchdog(!Boolean.TRUE.equals(req.getShowWatchdog()));   // 默认排除
        q.setCursorStartsAt(req.getCursorStartsAt());
        q.setCursorId(req.getCursorId());
        q.setLimit(clamp(req.getLimit()));

        // ⚠️ 租户边界：token 带 tenantInfo 时，入参一概不算数。
        //    查不到分配 → 空 list（**不是** null）—— 那会让 mapper 的 in (...) 变成 1=0，返回空集。
        //    **绝不能**把空 list 当成"不过滤"。
        var info = authContext.current();
        String tokenTenantId = (info != null && info.getTenantInfo() != null)
                ? info.getTenantInfo().getTenantId() : null;
        if (StringUtils.hasText(tokenTenantId)) {
            List<String> ns = allocs.listByTenantAndCluster(tokenTenantId, req.getClusterId()).stream()
                    .map(PlatformTenantNamespace::getNamespace)
                    .filter(StringUtils::hasText)
                    .distinct()
                    .toList();
            q.setNamespaces(ns);
        }
        // 无租户 claim（平台管理员）→ namespaces 保持 null = 不过滤
        return mapper.query(q);
    }
```

```java
@Service
@RequiredArgsConstructor
public class AlertService {

    private final PlatformAlertEventMapper mapper;
    private final PlatformTenantNamespaceMapper allocs;
    private final AuthContext authContext;
    private final RestClient.Builder restClientBuilder;      // 自检用的回环客户端
    private final String webhookToken;                       // = platform.alert.webhook.token
    private final int serverPort;                            // = server.port

    /** 固定值：自检造的告警用这个 alertname，便于筛出来与清理。 */
    static final String SELF_TEST_ALERTNAME = "PlatformSelfTest";

    public AlertService(PlatformAlertEventMapper mapper,
                        PlatformTenantNamespaceMapper allocs,
                        AuthContext authContext,
                        RestClient.Builder restClientBuilder,
                        @Value("${platform.alert.webhook.token}") String webhookToken,
                        @Value("${server.port}") int serverPort) {
        this.mapper = mapper;
        this.allocs = allocs;
        this.authContext = authContext;
        this.restClientBuilder = restClientBuilder;
        this.webhookToken = webhookToken;
        this.serverPort = serverPort;
    }
```

> ⚠️ `@RequiredArgsConstructor` 与显式构造函数**二选一** —— 有了 `@Value` 就只能写显式的那个，别两个都留。

自检方法：

```java
    /**
     * 自检：往**自己的回环地址**投一条合成告警（firing + resolved），走完整的
     * HTTP → ExemptPaths → 密钥校验 → 解析 → 落库链路。
     *
     * <p>为什么要它：集群侧配好 Alertmanager 之前，验收「链路通不通」只能等真告警。
     * 这个端点让平台能自证 —— 而且它验的是**平台这一侧**的全部环节，与集群那一侧正交。
     *
     * <p>⚠️ 刻意打**回环地址**（127.0.0.1:server.port）而不是直接调 ingest service：
     * 后者会把 HTTP 层、ExemptPaths 放行、密钥校验、body 解析全部绕过 —— 而那几层恰恰是最容易配错的。
     */
    public SelfTestResult selfTest(String clusterId) {
        String url = "http://127.0.0.1:" + serverPort + "/alert/webhook?clusterId=" + clusterId;
        // 造两条：一条 firing、一条 resolved，**startsAt 不同** ——
        // 同一个 fingerprint 的两个会话，正好把幂等键的另一半也验了。
        List<AlertWebhookRequest.Alert> payload = buildSelfTestAlerts(clusterId);
        int status;
        try {
            status = restClientBuilder.build().post().uri(url)
                    .header("Authorization", "Bearer " + webhookToken)
                    .contentType(MediaType.APPLICATION_JSON)
                    .body(payload)
                    .exchange((req, res) -> res.getStatusCode().value());
        } catch (Exception e) {
            return new SelfTestResult(-1, 0, List.of(), "回环请求失败：" + e.getMessage());
        }
        List<Long> ids = mapper.findIdsByAlertname(clusterId, SELF_TEST_ALERTNAME);
        return new SelfTestResult(status, ids.size(), ids, null);
    }

    /** 物理删。幂等 —— 已经没了也返回成功（清测试数据时连着点两下不该报错）。 */
    public void delete(long id) {
        mapper.deleteById(id);
    }

    /** 自检结果：三个数字定位链路断在哪一层。 */
    public record SelfTestResult(int status, int rowCount, List<Long> ids, String error) {}
```

> `buildSelfTestAlerts(clusterId)` 造两条告警：
> - `alertname = SELF_TEST_ALERTNAME`、`fingerprint = "platform-self-test"`（固定串，便于清理）
> - `labels.namespace` 取该集群任一真实分配（`allocs.listByTenantAndCluster` 拿不到就用 `selectByClusterAndNs` 的任一结果）；**一个都没有就留空** —— 空 namespace 也要能落库（Task 15 已覆盖）
> - 两条的 `startsAt` 相差 1 秒；一条 `status.state = "firing"`、一条 `"resolved"` 且带 `endsAt`
> - 数组顺序：**resolved 在前、firing 在后**（测试断言就是这个顺序）

`AlertController` 加：

```java
    @PostMapping("/self-test")
    @Operation(summary = "告警链路自检 —— 平台给自己投一条测试告警，验证整条链路")
    public ResponseData<AlertService.SelfTestResult> selfTest(@RequestParam String clusterId) {
        return new ResponseData<>(alertService.selfTest(clusterId));
    }

    @DeleteMapping("/{id}")
    @Operation(summary = "删除告警记录（清测试数据）")
    public ResponseData<Void> delete(@PathVariable long id) {
        alertService.delete(id);
        return new ResponseData<>();
    }
```
